# Curso de Análisis de Algoritmos

Repositorio correspondiente al curso de Análisis de Algoritmos. En este repositorio se almacenan los ejercicios y laboratorios evaluativos desarrollados durante el curso.

## Estructura del repositorio

- `benchmarks/`: Contiene las pruebas y mediciones de rendimiento de los algoritmos.
- `ejercicios-clase/`: Contiene los ejercicios y actividades desarrollados durante las clases.
- `laboratorios/`: Contiene los cinco informes de laboratorio evaluativos y sus respectivos archivos.
- `.gitignore`: Contiene los archivos y carpetas que Git debe ignorar y no incluir en el repositorio.
- `README.md`: Contiene la documentación general, descripción y estructura del repositorio.

## Propósito

El objetivo de este repositorio es organizar y documentar las actividades realizadas durante el curso, permitiendo llevar un registro de los ejercicios, laboratorios y análisis de rendimiento de los diferentes algoritmos.
